We are looking for a full-stack developer who builds web applications from the
database to the browser and ships them: typed front ends, the APIs behind them,
the tests that keep them working, and the pipeline that deploys them. You will
own features end to end and work through code review with the rest of the team.

## What you'll do

- Build responsive, accessible front ends in React and TypeScript, with HTML
  and CSS that meet WCAG 2.1 AA.
- Design REST APIs and build the services behind them in Python or
  JavaScript.
- Model data in a SQL database and change it safely through migrations.
- Write automated tests, including end-to-end browser tests with Playwright,
  and gate every change with CI in GitHub Actions.
- Ship through pull requests and code review, deploy with Docker to Linux
  servers, and keep production healthy after launch.

## Must-haves

- Production web applications delivered across both the front end and the
  back end.
- JavaScript and TypeScript with React, plus semantic HTML and CSS.
- Python or another server-side language for APIs and automation.
- REST API design, a SQL database such as SQLite, Git, and code review.
- Automated testing and CI/CD with GitHub Actions.

## Nice-to-haves

- Docker, Linux server deployment, and Bash scripting.
- Accessibility (WCAG 2.1 AA) and web performance work.
- E-commerce or CMS integrations (Shopify, WordPress, HubSpot).
- LLM-powered features inside web products.
