We are hiring a developer-first technical SEO: someone who improves search
performance by shipping code — site speed, structured data, crawlability, and
rendering — not by writing content calendars.

## What you'll do

- Diagnose and fix Core Web Vitals: LCP, CLS, INP; PageSpeed / Lighthouse
  audits turned into shipped fixes (image optimization, lazy loading, caching,
  render-blocking resources).
- Implement structured data with JSON-LD (product, article, organization
  schemas) and validate it end to end.
- Own on-page SEO in the codebase: semantic HTML5, meta and heading hierarchy,
  canonical URLs, redirects, sitemaps, and internal linking on CMS and
  e-commerce platforms (Shopify, HubSpot, WordPress).
- Handle JavaScript SEO: rendering strategies in React / Next.js, hydration
  cost, and crawlable client-side experiences.
- Build SEO tooling and automation: audits, content-lint guards (banned words,
  heading hierarchy, meta length), and monitoring for search algorithm-update
  drift.

## Must-haves

- Demonstrated Core Web Vitals / PageSpeed improvements on production sites
  with measurable results.
- JSON-LD structured data implementation experience.
- JavaScript (ES6+), HTML5, CSS3; React and Next.js rendering fundamentals.
- On-page SEO ownership across CMS or e-commerce platforms (Shopify, HubSpot,
  or WordPress).
- Git-based workflow; comfort turning audit findings into pull requests.

## Nice-to-haves

- SEO automation tooling in Python or Node.js; LLM-assisted content pipelines
  with deterministic lint guards.
- E-commerce SEO: product page optimization, catalog migrations, redirects.
- Analytics and Search Console-driven prioritization.
