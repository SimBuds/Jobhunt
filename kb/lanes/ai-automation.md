We are looking for a developer who builds AI automation: agentic pipelines,
LLM-powered tooling, and workflow automation that ships to production. You will
design and operate agents against LLM APIs (Claude API), run and tune local
LLM inference (Ollama), and wire AI capabilities into real products and
internal tools.

## What you'll do

- Build autonomous and semi-autonomous agents that plan, call tools, and
  persist durable memory across runs.
- Design prompt pipelines with deterministic validation and retry layers so
  LLM output is safe to ship (no-fabrication checks, schema-constrained JSON,
  lint guards).
- Host and optimize local LLM inference: quantized models, KV-cache tuning,
  flash attention, context-window management, GPU optimization.
- Expose AI capabilities through backend services: Python, FastAPI, REST APIs,
  Redis caching, PostgreSQL persistence, Docker / Docker Compose deployment.
- Automate end-to-end workflows: ingestion, scoring, content generation, and
  browser automation (Playwright) glued together with CI/CD (GitHub Actions).

## Must-haves

- Hands-on experience building AI automation with LLM APIs (Claude API or
  similar) and prompt engineering that survives production edge cases.
- Local LLM hosting and optimization experience (Ollama or similar).
- Python and TypeScript/JavaScript (Node.js) for services and tooling.
- FastAPI or Express service development; REST API design.
- Docker, Git, GitHub Actions CI/CD; PostgreSQL or MongoDB; Redis.
- Evidence of shipped agentic projects — personal or client work counts when
  it is real, running software.

## Nice-to-haves

- Agentic architecture patterns (planner/executor, tool servers, MCP).
- Structured-data / JSON-LD generation, retrieval pipelines, embeddings.
- Test automation with Jest or Playwright.
