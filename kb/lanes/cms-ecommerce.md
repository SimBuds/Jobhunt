We need a CMS and e-commerce developer who builds and migrates sites on
Shopify, WordPress and HubSpot CMS, working with marketing, SEO and design
teams from design to launch.

## What you'll do

- Build and customize Shopify themes: Liquid, Online Store 2.0 sections and
  JSON templates, metafields, and theme checks on every commit.
- Build and maintain WordPress sites: custom and child themes, Elementor Pro,
  ACF, PHP, WP-CLI, and managed hosting such as WP Engine.
- Develop HubSpot CMS themes: HubL custom modules, drag-and-drop templates
  and HubDB, built from Figma designs.
- Plan and run platform migrations: URL mapping, 301 redirects, launch gates
  and testing before cutover.
- Keep sites fast, accessible and findable: Core Web Vitals, Lighthouse,
  WCAG 2.1 AA, on-page and technical SEO, JSON-LD.

## Must-haves

- Shopify (Liquid) theme development on live stores.
- WordPress development with PHP, at the theme and plugin level.
- HubSpot CMS (HubL) or another hosted CMS such as Contentful.
- JavaScript, HTML and CSS.
- Site migrations with redirect mapping.

## Nice-to-haves

- Accessibility to WCAG 2.1 AA and Core Web Vitals work.
- GA4, GTM and Google Search Console.
- Git with GitHub Actions, Cloudflare, and Jira.
- Automating content work with Python or LLM tooling.
