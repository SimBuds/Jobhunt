Jobhunt: Local-First AI Job-Search Automation
Apr 2026 - Present
A job-search automation CLI that I built and use daily. It ingests jobs from nine public ATS sources, including Greenhouse, Lever, Ashby, Workday, SmartRecruiters, Workable, Recruitee, Adzuna, and Job Bank Canada. Sources run concurrently over async HTTP with individual rate limits.

Everything runs locally. Fit scoring, résumé tailoring, and cover-letter drafting use a quantized model through Ollama. Schema-constrained JSON generation keeps the pipeline reliable on consumer GPU hardware with no per-run API cost.

The system has a structural no-fabrication guarantee. Deterministic checks reject generated claims that cannot be traced to a verified profile snapshot. I built it this way because I would not submit a résumé claim I had not verified myself.

SQLite provides durable state with versioned migrations. Playwright handles form autofill in a headed browser, then stops before submission. I review and submit every application myself.
Roughly 700 tests, Ruff, and strict mypy checks gate every change.

Stack: Python, asyncio, Typer, Pydantic, SQLite, Ollama, Playwright, and pytest.Show less 

AI Context Stack: Custom Local LLMs from Layered Markdown
Mar 2026 - Present
A system for creating customized local LLMs without fine-tuning. I combine plain Markdown files for behavior, durable memory, and reusable reference material into a single system prompt, then run a builder that produces a ready-to-use Ollama model. Changing the model’s behavior is as simple as editing a Markdown file and running the build script again.

The project includes an evaluation suite for comparing candidate models across content, coding, and learning tasks. It measures output quality, generation speed, and VRAM use so I can choose a base model that fits the target hardware.

The runtime is tuned for local GPU constraints, including context length, KV cache settings, and flash attention.

All customization lives in version-controlled Markdown and passes through a deterministic build process. There are no opaque training runs, and every behavior change can be reviewed, reproduced, or reverted.

Stack: Ollama, Bash, Python, and Linux.Show less 

Auto-Agent: Autonomous Claude API Agent
Mar 2026 - Present
An autonomous agent that plans and executes tasks using the Claude API. A FastAPI capability server provides its tools, Postgres stores durable memory and task state, and Redis caches active context. The system runs continuously through Docker Compose on my own Linux infrastructure.

The design separates planning from capability. The model decides what to do, while a typed FastAPI server limits what it can actually do. Actions are permission-scoped and recorded for review instead of being executed through unrestricted commands.

Memory and task state persist across restarts, allowing the agent to resume work without losing its place. Getting that recovery path right was the hardest part of the project.

Stack: FastAPI, Claude API, Postgres, Redis, Docker, and Arch Linux.Show less
